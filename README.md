# 🚀 EngineerOS

> Build the Engineer You Want to Become.

EngineerOS is my long-term software engineering project and personal career operating system.

Instead of building many small tutorial projects, I am building one application that evolves as I learn.

Every new technology I learn becomes a new feature.

## Current Stack

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Node.js
- Express.js
- PostgreSQL

## Working Features

- Daily mission tracking with timers and browser-based recovery.
- DSA practice for Arrays, Strings, and Binary Search, with search, filters,
  sorting, progress tracking, and a continue-practicing prompt.
- PostgreSQL-backed DSA topics and problem-status persistence, with browser
  storage retained as an offline fallback.

## Local Backend Setup

1. Create `backend/.env` with `DB_USER`, `DB_HOST`, `DB_NAME`,
   `DB_PASSWORD`, and `DB_PORT` for your PostgreSQL database.
2. Run `backend/schema.sql` against that database.
3. In `backend`, run `npm start`.

The API runs at `http://localhost:3000`. The frontend is configured for the
usual Live Server addresses: `http://127.0.0.1:5500` and
`http://localhost:5500`.
